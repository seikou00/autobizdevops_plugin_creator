# 文档起草

## 步骤

1. 向用户确认文档的目标读者、要解决的问题和验收标准；信息不足时先提问，不要臆造需求；
2. 读取模板 `templates/DRAFT.md`，按模板的章节在 `FEATURE_DIR` 下写出 `DRAFT.md`；
3. 每个章节都要有实际内容。暂时无法确定的内容写在"待确认问题"中，不要留空章节；
4. 写完后向用户概述初稿要点，并列出待确认问题。

## 完成标准

- `DRAFT.md` 覆盖模板的全部章节；
- "目标"一节写明可以验证的验收标准。
