# 文档评审

## 步骤

1. 读取 `FEATURE_DIR` 下的 `DRAFT.md`；
2. 逐节检查：背景是否清楚、验收标准能否验证、方案是否可行、风险是否有应对；
3. 在 `FEATURE_DIR` 下写出 `REVIEW.md`，包含：
   - 问题清单：每条写明所在章节、问题、修改建议；
   - 单独一行结论，写成 `结论：通过` 或 `结论：需修改`；
4. 向用户说明结论和最重要的几条问题。

## 完成标准

`REVIEW.md` 有问题清单和结论行。推进到完成时框架会执行 `scripts/check_review.py` 检查这两项，不通过时按输出修改 `REVIEW.md`。
